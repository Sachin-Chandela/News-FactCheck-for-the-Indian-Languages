# Data Description — Project 1: Multilingual Fact-Checker

## 1. Overview
This project uses a custom merged dataset assembled from two locally curated CSV sources covering health and general fact-check claims. It is purpose-built for **multilingual claim verification** supporting Hindi, English, and code-mixed (**Hinglish**) text across four verdict categories.

---

## 2. Source Files
The dataset is generated by merging two raw files:
* **`facts_merged_final.csv`**: Primary source. Contains health-domain claims (nutrition, medicine, fitness, disease).
* **`factcheck_dataset_modified.csv`**: Secondary source. Provides additional breadth to label distribution, particularly for false and misleading categories.

---

## 3. Preprocessing
Handled by `src/preprocess.py`, the pipeline follows these steps:
1.  **Concatenation**: Merges sources and resets indexing.
2.  **Deduplication**: Drops rows with duplicate `claim` text (keeps first occurrence).
3.  **Label Normalization**: Maps string labels to integers:
    * `true` → **0**
    * `false` → **1**
    * `misleading` → **2**
    * `other` → **3**
4.  **Type Casting**: Ensures labels are `int` for PyTorch compatibility.
5.  **Evidence Handling**: Fills NaN evidence with empty strings (`""`) so rows are retained during training.

The final cleaned output is saved to `data/final_dataset.csv`.

---

## 4. Dataset Schema
| Column       | Type   | Description                                               |
| :----------- | :----- | :-------------------------------------------------------- |
| **claim**    | string | The fact claim to verify. Used in training and retrieval. |
| **evidence** | string | Supporting/contradicting text. May be empty.              |
| **label**    | int    | Target class (0-3).                                       |
| **source**   | string | Optional URL/publication name (inference only).           |

---

## 5. Train / Validation Split
The split is performed in `train_classifier.py` using `train_test_split`:
* **Train (90%)**: Used for model optimization.
* **Validation (10%)**: Held out for evaluation and best-model checkpointing.
* **Strategy**: Stratified on the `label` column with `random_state=42`.
* **Note**: No fixed test split is defined in the code.

---

## 6. Label Distribution & Balancing
The dataset is imbalanced (True/False are majority classes). This is handled via:
* **Balanced Class Weights**: Passed to `CrossEntropyLoss`.
* **Label Smoothing**: Factor of **0.1** applied to soften overconfident predictions.

---

## 7. Retrieval Index
* **Index Type**: `faiss.IndexFlatL2` (Exact L2 search).
* **Embedding Model**: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`.
* **Scope**: Built using the **full** `final_dataset.csv`. The retriever acts as a lookup database for all known facts.

---

## 8. Reduced / Subset Setup
For debugging or limited hardware:
* **Data Slicing**: Slice `final_dataset.csv` (e.g., `.head(200)` per label) to run a quick end-to-end sanity check.
* **NLI Optimization**: Swap `xlm-roberta-large-xnli` for a smaller model like `nli-MiniLM2-L6-H768` in `nli_verifier.py` to reduce VRAM usage.
